# ayunda-app — CryptoWeb Suite

**Tugas Pemrograman Web & Keamanan Siber**  
**Nama:** Ayunda

Aplikasi web interaktif **CryptoWeb Suite** untuk melakukan enkripsi dan dekripsi menggunakan tiga metode kriptografi:
1. **Classic Cipher** (Caesar Cipher & Vigenère Cipher)
2. **AES-256 Encryption** (Symmetric Block Cipher via CryptoJS)
3. **RSA Encryption** (Asymmetric Public/Private Key via JSEncrypt)

## Fitur Utama
- **Dark Mode Glassmorphism UI** (Responsif untuk Desktop & Mobile)
- **Interactive Cyber Sound FX Synthesizer** (Web Audio API)
- **Matrix / Cyber Decoding Output Animation**
- **Copy to Clipboard & Swap Output ke Input**
